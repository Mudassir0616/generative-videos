# 2D Motion Graphics & Kinetic Typography

A working reference distilled from curated roundups (Wyzowl, F. Learning Studio, B2W, Contra, Pexo, Todaymade, BuzzFlick) and motion design communities. Use it to pick a style, plan the piece, and execute it with consistent craft.

## 1. Pick the format first

Choose the type of piece before designing. Each has a different goal and pacing.

| Format | Goal | Typical length | Notes |
|---|---|---|---|
| Explainer (SaaS / problem-solution) | Make a product or idea easy to grasp | 60-90s (social teasers 15-30s) | One message only. Show the problem, then the solution. |
| Product / app demo | Show features in context | 30-90s | Animate UI elements, highlight one action per beat. |
| Whiteboard / cartoon 2D | Teach a concept in a friendly way | 60-120s | Hand-drawn feel, simple characters. |
| Brand / rebrand launch | Introduce a new identity | 15-60s | Show motion principles of the brand, not just the logo. |
| Logo / brand ID animation | Turn a static mark into an identity asset | 3-8s | Must work with and without sound. |
| Kinetic typography | Make words carry the message | 15-75s | Timing to audio is everything. |
| Data storytelling / year-in-review | Make numbers personal and shareable | 30-75s | Template scenes that accept different data. |
| Social loop / background | Attention and mood | 3-10s, seamless loop | Shape morphs, gradients, abstract motion. |

## 3. What the best pieces have in common

1. **One idea per piece.** Every scene advances the story; no decorative filler.
2. **Works muted.** Most social viewing is without sound, so the visuals and on-screen text must carry the message.
3. **Purposeful transitions.** A transition should move the story forward or connect two ideas (shape becomes icon, line becomes chart), not just fill time.
4. **Bold, simple visuals.** Strong shapes, limited palette, generous whitespace.
5. **Pacing and sound.** Motion lands on the beat of music or voice-over; sound design sells the impact.
6. **Consistent motion language.** Same easing, timing and entrance/exit logic throughout.
7. **Clear structure.** Hook, problem, solution, proof, call to action.

## 4. Workflow

1. **Brief**: audience, goal, platform (aspect ratio: 16:9, 9:16, 1:1), length, tone.
2. **Script / copy**: write the narration or on-screen text first. Keep lines short.
3. **Style frames**: design 3-5 key frames (colour, type, shape language) before animating.
4. **Storyboard**: one thumbnail per beat with duration and transition notes.
5. **Animatic**: rough timing against audio.
6. **Animate**: build in layers, easing first, polish later.
7. **Sound and finish**: music, SFX, export, check muted playback.

## 5. 2D motion principles (apply to every layer)

- **Easing**: never use linear for UI/graphic motion. Ease-out for entrances, ease-in for exits, ease-in-out for moves. Add slight overshoot for energy.
- **Anticipation and follow-through**: a small pull-back before a big move, a small settle after.
- **Stagger**: offset related elements by 2-6 frames instead of moving them together.
- **Hierarchy**: the most important element moves first and largest; supporting elements follow.
- **Squash and stretch**: use sparingly on shapes and characters to add weight.
- **Anchor points**: set rotation and scale origins deliberately.
- **Looping**: for loops, match first and last frames and keep motion cycles evenly divisible.
- **Duration guide**: small UI moves 150-300ms, element entrances 300-600ms, scene transitions 400-800ms.
- **Frame rate**: 24-30 fps for video, 60 fps for web/UI motion.

## 6. Kinetic typography playbook

**Core idea:** moving text is the visual. Every word's motion should reinforce its meaning.

**Techniques**
- Word-by-word reveals timed to speech; emphasise the key word with scale, weight or colour.
- Scale and position changes to show hierarchy (the important word gets big).
- Masked reveals, slide-ups from a baseline, and line-by-line wipes.
- Character-level animation (per-letter stagger, scramble, wave) for headlines.
- Text on a path, text morphing into icons, text replacing itself in place.
- Typography combined with shapes and simple illustration for context.
- Code-driven, templated scenes when data or personalisation is involved.

**Rules**
- Max 3-7 words visible at once unless it is a deliberate wall of text.
- Hold each phrase long enough to read (about 0.3s per word minimum, longer for key lines).
- Use 1-2 typefaces; contrast weight and size instead of adding fonts.
- Keep strong contrast and safe margins; check legibility on mobile.
- Match motion energy to tone: sharp and fast for punchy brand spots, slow and smooth for calm or educational pieces.
- Sync major hits to audio beats.
- Add captions/readable text so it works without sound.

**Storyboard tip:** list each line of copy, assign one motion verb to it (slam, slide, unfold, type, morph), then check that no two adjacent lines use the same move.

## 7. Style cookbook

| Style | Look | Motion |
|---|---|---|
| Flat geometric explainer | Solid shapes, limited palette, simple icons | Shapes morph into icons, smooth slides, scale pops |
| Whiteboard | Line art on light background | Draw-on strokes, hand movement, quick erases |
| Bold brand / rebrand | Big type, saturated colour blocks | Fast cuts, wipes, kinetic type, logo reveal at end |
| Gradient loop | Soft animated gradients, blurred shapes | Slow continuous drift, seamless loop |
| Data story | Clean charts, large numerals | Count-ups, bars growing, highlights on key values |
| Playful character | Simple rigged characters, expressive faces | Squash and stretch, overlapping action |
| Minimal product | Lots of whitespace, one accent colour | Subtle parallax, UI callouts, restrained easing |

## 8. Output checklist before delivering

- [ ] One clear message, stated in the first 3 seconds
- [ ] Reads and makes sense with the sound off
- [ ] Consistent easing, timing and palette
- [ ] Text readable on a phone, with safe margins
- [ ] Loop points clean (for loops)
- [ ] Correct aspect ratio and frame rate for the platform
- [ ] Logo or call to action held long enough at the end
- [ ] Exported formats match the destination (MP4, GIF, Lottie, WebM)

## 9. How to apply this skill

When asked for a motion graphic or kinetic type piece:
1. Confirm format, platform, duration and tone (ask only if not given).
2. Pick a style from section 7 and cite which reference style from section 2 it resembles.
3. Provide script, storyboard (scene, duration, motion, transition), and timing notes.
4. If building it, use the requested tool (Jitter, After Effects expressions, CSS/JS, Remotion, Lottie) and follow the principles in sections 5 and 6.
5. Run the checklist in section 8 before presenting.
